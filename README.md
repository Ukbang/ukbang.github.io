# Antigravity — AI 강사 포트폴리오

**Game · Learn · Fun** — 게임처럼 즐겁게 배웁니다.

방승욱 강사의 개인 포트폴리오 사이트입니다. AI, 데이터 사이언스, Python 교육 전문가로서의 강의 이력, 전문 분야, 수강생 후기를 소개합니다.

🌐 **라이브 사이트:** https://ukbang.github.io

---

## 기술 스택

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **폰트:** Pretendard (CDN)
- **아이콘:** 커스텀 SVG 아이콘 (19종)
- **애널리틱스:** Google Tag Manager
- **문의 폼:** Google Forms

---

| 섹션 | 내용 |

## 전문 강의 영역

1. **Python** — 데이터 수집·전처리·자동화 스크립팅
2. **AI** — 머신러닝 & 딥러닝 모델
3. **생성형 AI (LLM)** — AI 서비스 개발 및 콘텐츠 제작
4. **RAG & 지식베이스** — 검색 증강 생성(RAG) 구현
5. **AI 에이전트 개발** — 자율 워크플로우 설계
6. **데이터 분석 & BI** — Tableau / PowerBI 대시보드

## 프로젝트 구조

```
Antigravity/
├── index.html          # 메인 페이지
├── script.js           # 스크롤 애니메이션, 햄버거 메뉴
├── style.css           # 스타일 (CSS 변수, 반응형 레이아웃)
├── icons/
│   ├── icons_output/   # SVG 아이콘 19종
│   └── split_icons.py  # SVG 분리 유틸리티 스크립트
└── images/             # 프로필 및 강의 이미지
```

---

## 디자인 특징

- 메인 컬러: Indigo `#4F46E5`
- CSS Grid & Flexbox 기반 반응형 레이아웃
- Intersection Observer API를 활용한 fade-in 애니메이션
- `clamp()`를 활용한 유동적 타이포그래피
- 모바일 햄버거 메뉴 지원
